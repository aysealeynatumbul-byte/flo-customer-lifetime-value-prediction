# FLO Customer Lifetime Value (CLTV) Prediction

## Project Overview

This project focuses on predicting Customer Lifetime Value (CLTV) using historical customer transaction data from FLO.

The goal is to estimate future customer value and support data-driven marketing and customer segmentation decisions.

## Technologies Used

- Python
- Pandas
- BG/NBD Model
- Gamma-Gamma Model
- Lifetimes Library
- Scikit-learn

## Project Workflow

1. Data preprocessing and outlier handling
2. Feature engineering
3. Customer purchase behavior analysis
4. BG/NBD modeling for expected purchases
5. Gamma-Gamma modeling for expected transaction value
6. Customer Lifetime Value estimation
7. Customer segmentation based on predicted CLTV

## Business Value

The project demonstrates how customer analytics can support marketing strategies, customer segmentation, and customer relationship management.
